# SCT_ML_3: SVM Cats vs Dogs Classification
SkillCraft Technology - Machine Learning Internship Task 3

## Results
- **Accuracy**: 61.25%
- **Model**: SVM with RBF Kernel, C=10, gamma=0.001
- **Features**: PCA with 150 components from 64x64 grayscale images
- **Dataset**: 2000 images from Kaggle Dogs vs Cats
- **Training Time**: 0.1 minutes

## Tech Stack
Python, OpenCV, Scikit-learn, NumPy, Matplotlib, Joblib
